# demystifying-rl-finetuning-web

Project page for *Demystifying Reinforcement Learning Post-Training of Language Models*.

Static HTML/CSS, no build step. Open `index.html` locally, or serve it:

```
python3 -m http.server
```

Files:

- `index.html` — the page
- `style.css` — all styling
- `figures/` — figures extracted from the paper
- `paper.pdf` — the paper

To deploy on GitHub Pages: Settings → Pages → deploy from `main`, root folder.
